# CloudCull Dashboard

The **CloudCull Dashboard** visualizes audit reports generated by the core engine. It is a review surface, not the primary control plane for active operations.

> **[VIEW LIVE DEMO](https://daretechie.github.io/cloudcull/)**

## Features
*   **Candidate Review:** See which instances are marked as `ZOMBIE` candidates.
*   **Financial Estimate:** Calculate potential monthly savings from known pricing data.
*   **Attribution:** Show available owner or launch attribution for review.
*   **Secure API Integration:** Consume logs and reports via the `dashboard_server.py` API for local runs.
*   **Dual-Mode Hosting:** Support local review mode or read-only static audit publishing.

## Tech Stack
*   **Vite:** Frontend build tool.
*   **React:** Component-based UI.
*   **CSS:** Dashboard styling.

## Setup & Build

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally (Secure)
To view live logs and real audit data, use the secure backend:
```bash
python3 src/dashboard_server.py
```
Navigate to `http://localhost:8080`.

### 3. Dev Mode (Frontend Only)
```bash
npm run dev
```
Navigate to `http://localhost:5173`. *Note: Secured logs will not be visible in this mode.*

### 3. Build for Production
```bash
npm run build
```
This generates static assets in `dist/` that can be deployed to any static host (GitHub Pages, Netlify, S3).

## 🔄 Integration Flow
1.  **Core Engine** runs `main.py` and outputs `report.json`.
2.  **GitHub Action** saves this JSON artifact.
3.  **Deploy Job** copies the `dist/` folder and the new `report.json` to the `gh-pages` branch.
